# Mission

> 우리가 매일 하는 일

## Statement

**문서 기반 Multi-Agent 협업으로 Task를 정의·설계·구현·검증·배포하며, 모든 산출물을 Git에 남겨 재현 가능한 소프트웨어 생산 체계를 운영한다.**

## How We Operate

1. **문서 우선**: 작업 시작 전 관련 Role, Skill, Workflow, Memory를 읽는다.
2. **역할 명확화**: 각 Agent는 자신의 Role 문서에 정의된 R&R만 수행한다.
3. **워크플로우 준수**: 임의 단계 건너뛰기를 금지한다. 예외는 Escalation으로만 처리한다.
4. **결정 기록**: 아키텍처·기술 선택은 ADR로 남긴다.
5. **학습 축적**: 실패·성공 모두 Lessons Learned Memory에 기록한다.

## Success Metrics

| Metric | Target |
|--------|--------|
| Workflow Completion Rate | ≥ 90% |
| Document Coverage (산출물→문서) | 100% |
| ADR Coverage (기술 결정) | 100% |
| Rework due to missing docs | ≤ 10% |
| Human Escalation Rate | ≤ 20% |
