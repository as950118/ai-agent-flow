# Vision

> 우리가 向か는 미래

## Statement

**AI Agents가 실제 소프트웨어 회사처럼 협업하여, 아이디어에서 배포까지 신뢰할 수 있는 소프트웨어를 지속적으로 생산하는 Operating System을 만든다.**

## Future State (3년)

- 모든 Feature는 PRD → Architecture → Implementation → Review → QA → Release 파이프라인을 Agent 협업으로 완수한다.
- 모든 의사결정은 ADR로 추적 가능하며, Memory에 축적된 Lessons Learned가 재작업을 줄인다.
- 인간 Operator는 전략·승인·예외 처리에 집중하고, 루틴 실행은 Agent가 담당한다.
- Git Repository가 회사의 Single Source of Truth가 된다.

## Non-Goals

- 인간을 완전히 대체하는 것이 아니다.
- 추측 기반 자동 코딩을 허용하지 않는다.
- 문서 없는 암묵지(tribal knowledge)에 의존하지 않는다.
